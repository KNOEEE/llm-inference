# Projects

| 项目 | 开始阶段 | 目标 |
|---|---|---|
| toy-transformer | Phase 1 | 纯 PyTorch decoder 与 KV cache |
| qwen-inference | Phase 2 | 记录 Tiny-LLM 集成和对照实验 |
| kernel-lab | Phase 2/4/5 | 同一算子的跨后端实现 |
| scheduler-simulator | Phase 2/3 | CPU 可测的调度与 block 状态机 |
| serving-benchmark | Phase 3 | 统一 API、load generator 和指标 |
| capstone | Phase 8 | 最终可复现实验 |
