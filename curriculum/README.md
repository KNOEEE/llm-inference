# Curriculum

课程文档按阶段和周组织，代码不按周复制。每周从对应文档开始，完成交付物和验收标准后再更新状态。

| 阶段 | 周数 | 目录 |
|---|---:|---|
| PyTorch 与 Transformer 基础 | W01–W10 | `phase-01-foundations/` |
| Tiny-LLM 与 serving 核心 | W11–W28 | `phase-02-tiny-llm/` |
| 工程与测量 | W29–W32 | `phase-03-engineering/` |
| CUDA | W33–W36 | `phase-04-cuda/` |
| Triton | W37–W40 | `phase-05-triton/` |
| Nano-vLLM | W41–W44 | `phase-06-nanovllm/` |
| vLLM | W45–W48 | `phase-07-vllm/` |
| 毕业项目 | W49–W52 | `phase-08-capstone/` |

## 每周完成条件

每周至少留下四类证据：概念说明、可运行实现、正确性测试、学习总结。涉及性能时再增加固定 workload、环境信息和原始结果。
