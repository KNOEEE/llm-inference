# Phase: CUDA Foundations

- Weeks: W33-W36
- Primary environment: NVIDIA Linux

## Entry criteria

Pass the GPU readiness checks and have a PyTorch oracle plus a disciplined benchmark harness.

## Phase outcome

Understand grids, blocks, warps, and the memory hierarchy, and be able to implement, validate, and profile simple CUDA kernels.
